Cómo se publican los cambios

Los cambios que hacés acá quedan guardados en este navegador hasta que toques Publicar ahora. Hasta ese momento la web sigue mostrando lo anterior, así que podés editar tranquila sin miedo a romper nada.

  1. Editá lo que quieras acá abajo.
  2. Publicar ahora, el botón dorado de arriba. Listo: la web se actualiza sola en menos de un minuto. No hay que tocar la Terminal.

¿Agregaste un producto nuevo? La foto es el único paso que todavía va a mano: guardala en assets/img/ de la carpeta del proyecto con el nombre exacto que pusiste en el campo Foto, y subila con git add -A && git commit -m "foto nueva" && git push Mientras no esté la foto, el producto queda oculto en la tienda.

Descargar archivo es el plan B: te baja el data.js para guardarlo a mano si algún día falla la publicación automática.
